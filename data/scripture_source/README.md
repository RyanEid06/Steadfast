# Curated offline Scripture provenance

`scripture_catalog.json` contains exactly 500 deliberately chosen, non-overlapping passages: 249 Old Testament and 251 New Testament entries, covering all 66 books. Its 1,263 complete verses address trust, temptation, self-control, prayer, mercy, renewal, courage, grief, comfort, wisdom, community and hope. Familiar anchors receive more space in Psalms, Proverbs, the Gospels and letters; short books still contribute meaningful passages. This is a curated encouragement collection, not a substitute for reading the surrounding chapter. Tags describe themes, not clinical advice or a promise of a particular recovery outcome.

The translation is **World English Bible Classic (WEB), American English, 2020 stable text edition**, using “Yahweh”. Its publisher identifies the source and edition at [eBible.org](https://ebible.org/find/details.php?id=eng-web), supplies the [machine-readable VPL archive](https://ebible.org/Scriptures/eng-web_vpl.zip), and dedicates the translation to the [public domain](https://ebible.org/eng-web/copyright.htm). “World English Bible” is the publisher's trademark. The full publisher archive contains additional books; this collection and its verse bounds use only the app's existing Protestant 66-book canon.

`provenance.json` pins the downloaded archive SHA-256, both original source-member hashes, the retrieval date, counts and output hashes. `eng-web-selected.xml` retains the **literal publisher XML lines** for every selected verse. It is independent text evidence, not text reconstructed from the runtime JSON. `chapter_verse_counts.json` records bounds for all 1,189 canonical chapters, derived from the complete official source. The runtime bounds asset uses the app's numeric book IDs. Neither the publisher archive nor unused full Bible text is packaged in the app.

The import script cross-checks every canonical verse in the publisher's independently formatted XML and VPL text members before extracting anything. XML and VPL use different book abbreviations for several books; the script explicitly maps these. It keeps exact wording, Unicode punctuation, and publisher superscriptions included within numbered verses. It only removes leading/trailing whitespace from each source verse and joins consecutive verses with one space; it never truncates, paraphrases, strips superscriptions, or supplies missing words. Passage IDs encode the canonical USFM book code and zero-padded chapter/start/end; references use the app's canonical book names. There are no overlapping passages or duplicate full passage texts.

Reproduce with Python 3 (standard library only), from the repository root:

```text
python -X utf8 tools/import_scripture.py
python -X utf8 tools/import_scripture.py --source-archive path/to/eng-web_vpl.zip
```

The first command verifies checked-in assets and source evidence entirely offline. The second rebuilds from the **exact pinned archive**, then runs the same checks. Retrieve the archive separately using the publisher link above; the script makes no network requests. A different upstream archive is rejected and requires an explicit source/edition review before changing the pin. Keep the original downloaded archive as local evidence if future online source bytes change.

`data/scripture_curation.tsv` is the human-reviewable selection manifest, with one row per passage and themes individually assigned to that passage's text/context. It includes anxiety, fear, loneliness, sadness, hopelessness, guilt, forgiveness, repentance, love, identity, peace, renewal, temptation, sexual temptation, self-control, strength, perseverance, endurance, discipline, wisdom, courage, prayer, trust, hope, gratitude, anger, patience, bondage and freedom. Each of these themes has at least three relevant passages; `themeCounts` in the provenance records the actual distribution. Sexual-temptation tags identify the body/lust context of 1 Corinthians 6:19-20, Romans 13:12-14 and 2 Timothy 2:22-24; they are not applied indiscriminately to all temptation verses.

Editing the manifest requires a rebuild from the pinned archive. Runtime and reference catalogs must remain byte-identical; targeted `.gitattributes` rules preserve LF bytes for reproducible hashes across Windows and other checkouts. The JVM `ScriptureCatalogTest` independently checks every catalog reference/text against the retained publisher XML, manifest and full chapter bounds; checks all counts/canon/overlaps/checksums/theme coverage; and exercises malformed catalog rejection. These source files are development/test evidence only. The app uses bundled assets with no network permission or runtime download.
